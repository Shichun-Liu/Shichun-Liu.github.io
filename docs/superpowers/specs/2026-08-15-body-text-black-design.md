# 正文纯黑颜色调整设计

## 目标

将网站主要正文颜色从当前的 `$dark-gray` 改为纯黑色 `#000`，同时保留日期、标签、引用和其他辅助信息现有的灰色层级。

## 方案

仅修改 `_sass/_variables.scss` 中的 `$text-color`，将其值设为 `#000`。继续使用 `$text-color` 的页面正文和博客正文会随之变黑；`_sass/_post.scss` 中以 `#777` 或 `#555` 显式设置的日期、标签、引用等文字保持不变。链接仍使用现有的蓝色配置。

不新增选择器，也不修改背景、边框、导航或代码高亮颜色。

## 验证

运行现有的 Jekyll 构建，确认 SCSS 可以编译。预览首页、About 页面和博客文章，确认正文为黑色，日期、标签及引用仍为灰色，链接仍为蓝色。
